# Standards de Certification Carbone Internationaux
## Verra (VCS) · Gold Standard (GS4GG) · Comparaison & Recommandations

> Document de référence pour l'implémentation progressive de CarbonTrack Gabon.
> Compilé à partir des sources officielles Verra et Gold Standard (2024–2025).

---

## 1. Vue d'Ensemble des Deux Standards

| Critère | **Verra VCS** | **Gold Standard GS4GG** |
|---|---|---|
| Nom complet | Verified Carbon Standard | Gold Standard for the Global Goals |
| Fondé par | Verra (Washington DC) | WWF + ONG (Genève, 2003) |
| Part de marché 2023 | **48%** des émissions certifiées mondiales | **20%** |
| Unité émise | VCU (Verified Carbon Unit) | VER (Verified Emission Reduction) |
| 1 unité = | 1 tCO₂e réduite/retirée | 1 tCO₂e réduite/retirée |
| Secteurs couverts | 18 scopes sectoriels | Énergie, eau, déchets, forêts, communautés |
| Focus SDGs | Non (optionnel via labels) | **Obligatoire** (min. 3 SDGs dont SDG13) |
| Vérificateurs | VVBs accrédités Verra | VVBs approuvés Gold Standard |
| Plateforme | Verra Registry / Project Hub | Gold Standard Impact Registry |
| Adapté Afrique | ✅ Très fort (REDD+ africain dominant) | ✅ Fort (projets communautaires) |

## 2. Verra VCS — Processus Complet

### 2.1 Étapes de Certification

```
ÉTAPE 1 — DÉVELOPPEMENT DU PROJET
  ├── Choisir une méthodologie approuvée (VM00XX)
  ├── Définir le périmètre du projet
  ├── Calculer le scénario de référence (baseline)
  ├── Démontrer l'additionnalité
  └── Rédiger le Project Description (PD)

ÉTAPE 2 — LISTING (Pipeline)
  ├── Créer un compte sur Verra Project Hub
  ├── Soumettre le Project Description (format v4.4)
  ├── Payer les frais de listing
  └── Statut : "Project Pipeline" (visible publiquement)

ÉTAPE 3 — VALIDATION (avant enregistrement)
  ├── Sélectionner un VVB accrédité Verra
  ├── Le VVB reçoit le dossier complet :
  │   ├── Project Description (PD)
  │   ├── Calculs baseline et additionnalité
  │   └── Plan de surveillance (Monitoring Plan)
  ├── Audit du VVB (terrain + bureau)
  └── Le VVB émet un Rapport de Validation

ÉTAPE 4 — ENREGISTREMENT
  ├── Soumettre le Rapport de Validation à Verra
  ├── Verra fait un contrôle qualité (QA)
  ├── Payer les frais d'enregistrement
  └── Statut : "Registered Project"

ÉTAPE 5 — MISE EN ŒUVRE & SURVEILLANCE
  ├── Mettre en œuvre le projet selon le Monitoring Plan
  ├── Collecter les données d'émissions
  ├── Rédiger les Rapports de Surveillance (Monitoring Reports)
  └── Soumission des rapports à intervalles définis

ÉTAPE 6 — VÉRIFICATION (périodique)
  ├── VVB examine les Monitoring Reports
  ├── Audit des données réelles vs prévisions
  ├── Vérification absence de double comptage
  └── Le VVB émet un Rapport de Vérification

ÉTAPE 7 — ÉMISSION DES VCUs
  ├── Soumettre le Rapport de Vérification à Verra
  ├── Verra QA (contrôle qualité basé sur le risque)
  ├── VCUs émis avec numéros de série uniques
  └── VCUs inscits dans le registre Verra

ÉTAPE 8 — TRADING / RETIREMENT
  ├── VCUs peuvent être vendus sur le marché volontaire
  └── Retirement = compensation carbone de l'acheteur
```

### 2.2 Documents Requis (Verra VCS)

| Document | Phase | Description |
|---|---|---|
| **Project Description (PD)** | Listing + Validation | Document maître décrivant le projet |
| **Monitoring Plan** | Validation | Plan de suivi des émissions |
| **Validation Report** | Validation | Rapport du VVB |
| **Registration Representation** | Enregistrement | Déclaration légale signée |
| **Monitoring Report** | Vérification | Rapport de suivi périodique |
| **Verification Report** | Vérification | Rapport du VVB sur les résultats réels |
| **Issuance Representation** | Émission VCUs | Déclaration légale pour émission |
| **AFOLU Non-Permanence Risk Report** | AFOLU only | Évaluation risque de non-permanence |

### 2.3 Méthodologies Verra par Type de Projet

| Type de Projet | Méthodologie | Description |
|---|---|---|
| **REDD+ (éviter déforestation)** | **VM0007 / VM0048** | Framework REDD+ complet. VM0048 remplace VM0007 (nov. 2023) |
| **Déforestation non planifiée** | **VM0015** | Prévention avant qu'elle se produise |
| **Reforestation / ARR** | **VM0047** | Afforestation, Reforestation, Revégétation |
| **Gestion améliorée des forêts** | **VM0010 / VM0012** | IFM — Improved Forest Management |
| **Agriculture régénérative** | **VM0017 / VM0042** | Sols agricoles, pratiques durables |
| **Énergie renouvelable (solaire, éolien)** | **AMS-I.D / AMS-I.F** | Petite et grande échelle |
| **Biogaz / Déchets** | **AMS-III.R / VM0025** | Valorisation du méthane |
| **Cuisson propre** | **AMS-II.G** | Cuiseurs améliorés pour ménages |
| **Transport** | **AMS-III.C** | Réduction émissions transport |

### 2.4 Frais Verra (estimatifs)

| Étape | Coût estimatif |
|---|---|
| Listing | ~$350 |
| Enregistrement | ~0.10$/VCU (min. $500) |
| Vérification annuelle | $5 000 – $50 000 (selon VVB) |
| VVB (validation complète) | $15 000 – $80 000 |

### 2.5 Délais Verra

| Phase | Durée estimative |
|---|---|
| Préparation du PD | 3–12 mois |
| Validation VVB | 2–6 mois |
| Enregistrement Verra | 1–3 mois |
| Première émission VCUs | 6–24 mois après démarrage |
| Cycle de vérification | Tous les 1–5 ans |

## 3. Gold Standard GS4GG — Processus Complet

### 3.1 Étapes de Certification (8 étapes officielles)

```
PRÉ-CERTIFICATION — Préparation
  ├── Identifier la méthodologie applicable
  ├── Vérifier conformité avec GS4GG Principles & Requirements
  ├── Évaluer les principes de sauvegarde (safeguards)
  ├── Préparer les estimations d'impact
  ├── Créer un compte sur Gold Standard Impact Registry
  └── Organiser la consultation des parties prenantes

ÉTAPE 1 — Consultation des Parties Prenantes
  ├── Réunion de consultation formelle (obligatoire)
  ├── Documentation : Rapport de Consultation
  └── Les communautés affectées doivent avoir voix au chapitre

ÉTAPE 2 — Preliminary Review (Examen Préliminaire)
  Documents requis :
  ├── Formulaire de demande de Preliminary Review
  ├── Draft du Rapport de Consultation des Parties Prenantes
  ├── Lettre de couverture GS4GG signée
  ├── Conditions d'utilisation signées
  └── Paiement des frais
  Délai : 4 semaines (réponses complétude sous 2 semaines)
  Résultat : Statut "Gold Standard Project Listed"

ÉTAPE 3 — Validation par VVB Indépendant
  Documents requis pour le VVB :
  ├── Project Design Document (PDD) complet
  ├── SDG Impact Tool (estimation min. 3 SDGs + SDG13)
  ├── Feuille de calcul réductions d'émissions ex-ante
  ├── Évaluation des principes de sauvegarde
  ├── Rapport de Consultation des Parties Prenantes final
  └── Plan de Surveillance
  Délai : Planifié avec VVB, dans les 2 ans après listing

ÉTAPE 4 — Design Certification Review
  Gold Standard vérifie :
  ├── Opinion positive de validation du VVB
  ├── Rapport de Validation final soumis
  ├── PDD approuvé soumis
  └── Paiement des frais de Design Review
  Délai : min. 4 semaines
  Résultat : Statut "Gold Standard Certified Design"
            → Documents rendus publics

PHASE INTERMÉDIAIRE — Mise en Œuvre & Surveillance
  ├── Mettre en œuvre le design certifié
  ├── Rapport Annuel (années sans vérification)
  ├── Rapport de Surveillance (années de vérification)
  └── Engagement continu des parties prenantes

ÉTAPE 5 — Vérification par VVB Indépendant
  Documents requis :
  ├── Rapport de Surveillance complété
  ├── Feuille de calcul réductions d'émissions ex-post
  ├── SDG Impact Tool (données réelles)
  └── Données primaires pour évaluation
  Délai : min. une fois par cycle de 5 ans
          première vérif dans les 2 ans après certification design

ÉTAPE 6 — Performance Review
  Gold Standard vérifie :
  ├── Opinion positive de vérification du VVB
  ├── Rapport de Vérification final soumis
  ├── Rapport de Surveillance approuvé
  └── Paiement des frais de Performance Review
  Délai : min. 3 semaines
  Résultat : Statut "Certified Gold Standard Project"
            → Crédits carbone émis automatiquement

ÉTAPE 7 — Renouvellement Design Certification (Validation)
  Tous les 5 ans :
  ├── Mettre à jour PDD avec nouvelles méthodologies
  ├── Redéfinir le scénario baseline
  ├── Démontrer le besoin de financement continu
  └── Soumettre PDD et SDG Impact Tool au VVB

ÉTAPE 8 — Renouvellement Design Certification (Review)
  Gold Standard vérifie le renouvellement
  Cycle de renouvellement tous les 5 ans
```

### 3.2 Documents Requis (Gold Standard)

| Document | Phase | Spécificité GS |
|---|---|---|
| **Project Design Document (PDD)** | Étapes 2–3 | Inclut impacts SDGs |
| **Rapport de Consultation** | Étape 1–3 | Obligatoire (parties prenantes) |
| **SDG Impact Tool** | Étapes 3 et 5 | Min. 3 SDGs + SDG13 obligatoire |
| **Safeguarding Principles Assessment** | Étape 3 | Évaluation sauvegardes sociales/environnementales |
| **Monitoring Plan** | Étape 3 | Plan de suivi intégré au PDD |
| **Validation Report** | Étape 4 | Rapport VVB indépendant |
| **Annual Report** | Phase intermédiaire | Rapport annuel (hors année vérification) |
| **Monitoring Report** | Étape 5 | Rapport suivi pour vérification |
| **Verification Report** | Étape 6 | Rapport VVB performance réelle |

### 3.3 Méthodologies Gold Standard par Type de Projet

| Type de Projet | Méthodologie GS | Description |
|---|---|---|
| **Énergie renouvelable (solaire, éolien)** | **GS-RE-001 / TPDDTEC** | Centrales, systèmes off-grid |
| **Accès à l'énergie / Cuisson propre** | **AMS-II.G + GS overlay** | Cuiseurs propres pour ménages ruraux |
| **Eau potable** | **AMS-III.AV** | Purification eau, réduction combustible bouillir |
| **Reforestation / Agroforesterie** | **GS AFOLU (IFM/ARR)** | Gestion forêts, reboisement |
| **Gestion des déchets / Biogaz** | **AMS-III.R / AMS-III.G** | Déchets ménagers, biogaz |
| **Transport propre** | **AMS-III.C** | Véhicules électriques, transport en commun |
| **Efficacité énergétique bâtiment** | **AMS-II.C** | Isolation, systèmes efficaces |

### 3.4 Exigence SDG (spécifique Gold Standard)

Le Gold Standard exige que chaque projet démontre un impact positif sur **minimum 3 ODD/SDGs**, dont **SDG13 (Lutte contre les changements climatiques) obligatoire** :

| ODD | Pertinence Afrique/Gabon |
|---|---|
| SDG13 — Climat | **Obligatoire** |
| SDG15 — Vie terrestre | Forêts, biodiversité |
| SDG7 — Énergie propre | Solaire rural, cuisson |
| SDG6 — Eau propre | Purification eau |
| SDG8 — Travail décent | Emplois locaux |
| SDG1 — Pas de pauvreté | Revenus communautaires |

### 3.5 Frais Gold Standard (estimatifs)

| Étape | Coût estimatif |
|---|---|
| Preliminary Review | $750 – $1 500 |
| Design Review | $2 000 – $5 000 |
| VVB Validation | $10 000 – $50 000 |
| Performance Review | $1 500 – $3 000 |
| VVB Vérification | $5 000 – $30 000 |
| Émission crédits | ~0.05$/crédit (min.) |

### 3.6 Délais Gold Standard

| Phase | Durée |
|---|---|
| Preliminary Review | 4 semaines |
| Validation VVB | planifié, dans les 2 ans après listing |
| Design Review | 4+ semaines |
| Vérification VVB | dans les 2 ans après certification design |
| Performance Review | 3+ semaines |
| Cycle renouvellement | Tous les 5 ans |

> **Règle Paris 2026 :** À partir du 1er janvier 2026, tous les crédits Gold Standard avec millésimes ≥ 2026 devront utiliser les règles Paris-alignées (additionnalité renforcée, meilleur traitement des fuites, données de meilleure qualité).

## 4. Comparaison Directe VCS vs Gold Standard

| Critère | Verra VCS | Gold Standard |
|---|---|---|
| **Rigueur scientifique** | Très haute | Très haute |
| **Exigence sociale** | Moyenne | **Très haute** (SDGs, safeguards) |
| **Flexibilité sectorielle** | **Très haute** (18 scopes) | Moyenne (énergie, forêts, eau) |
| **Reconnu par corporates** | ✅ Leader mondial | ✅ Très reconnu |
| **Adapté projets REDD+** | ✅ Dominant (VM0007/VM0048) | ✅ Possible (AFOLU) |
| **Adapté projets sociaux** | Moins | **Oui — SDG overlay obligatoire** |
| **Coût global** | Moins élevé | Plus élevé |
| **Délai de certification** | 12–24 mois | 18–36 mois |
| **Prix marché VCU/VER** | $3 – $15/t | **$8 – $40/t** (premium) |
| **Compatible avec certif. nationale** | ✅ Oui (layers) | ✅ Oui (layers) |

## 5. MRV — Mesure, Reporting, Vérification

### Composantes MRV communes aux deux standards

```
M — MESURE
  ├── Scénario de référence (Baseline)
  │   Que se passerait-il sans le projet ?
  │   Méthode : historique, projection, benchmark sectoriel
  ├── Émissions du projet
  │   Émissions liées à la mise en œuvre
  └── Fuites (Leakage)
      Émissions déplacées en dehors du périmètre

R — REPORTING
  ├── Rapport de Surveillance périodique
  ├── Calcul des réductions nettes :
  │   Réductions = Baseline - Projet - Fuites
  └── Données primaires sourcées et vérifiables

V — VÉRIFICATION
  ├── VVB indépendant accrédité
  ├── Audit des données d'activité
  ├── Vérification terrain (site visit)
  └── Rapport de Vérification → Émission crédits
```

### Additionnalité (concept fondamental)
Le projet doit prouver qu'**il n'aurait pas eu lieu sans le financement carbone** (test d'additionnalité). Les deux standards exigent une démonstration rigoureuse via :
- Analyse barrières (financières, technologiques, réglementaires)
- Test de pratique courante (le projet est-il courant dans le secteur ?)
- Analyse investissement (le projet est-il financièrement viable sans les crédits ?)

## 7. Recommandation Stratégique pour CarbonTrack

### Roadmap d'implémentation

```
PHASE 1 — MAINTENANT
  Certification Nationale OGEC/CNC (Gabon)
  → Toutes les entreprises gabonaises
  → Conformité légale obligatoire
  → CarbonTrack = plateforme agréée de soumission

PHASE 2 — 6 à 12 mois
  Gold Standard pour les entreprises souhaitant
  une reconnaissance internationale
  → Avantage : prime de prix ($8–$40/t vs $3–$15/t)
  → Avantage : storytelling SDGs fort pour reporting RSE
  → CarbonTrack = assistant de préparation des dossiers GS

PHASE 3 — 12 à 24 mois
  Verra VCS pour les projets REDD+ et forêts
  → Notamment pour les ONG partenaires (quand réactivé)
  → VM0048 pour les projets REDD+ au Gabon
  → CarbonTrack = plateforme de génération de PDD

PHASE 4 — Long terme
  Plan Vivo pour les projets communautaires
  → Projets agroforestiers des villages
  → 60% des revenus aux communautés locales
```

### Pourquoi Gold Standard en Phase 2 ?

1. **Prix plus élevé** (+100–200% vs VCS) → meilleur retour pour les entreprises
2. **SDG alignment** → s'intègre parfaitement au reporting RSE/ESG des grandes entreprises
3. **Compatible national** → peut coexister avec la certification OGEC/CNC comme "couche supérieure"
4. **Plus facile à vendre** en Afrique centrale que VCS (image WWF, ONG internationale)
