Section 04

Infrastructure Cloud & Hébergement

Page 6

Le déploiement en production de CarbonTrack requiert une infrastructure cloud managée garantissant haute disponibilité, sécurité des données et scalabilité automatique. Amazon Web Services (AWS) a été retenu comme fournisseur principal pour sa présence mondiale et son SLA de 99,9%.

Services AWS — Détail & Justification

Service AWSSpécificationNécessité Technique
EC2 — Serveur Application Critique t3.medium (2 vCPU, 4GB RAM) Hébergement du serveur Next.js. t3.medium requis : gestion des workers Node.js concurrents, compilation PDF, calculs GES en temps réel
RDS PostgreSQL — Base de données managée Critique db.t3.small · Multi-AZ Gestion automatique des sauvegardes (rétention 7 jours), réplication Multi-AZ pour haute disponibilité, mises à jour de sécurité automatiques
CloudFront — CDN Global Distribution globale Livraison rapide des assets statiques (JS, CSS, images) depuis des edge locations proches des utilisateurs africains. Réduit la latence de 60%
S3 — Stockage Objet Standard + Intelligent-Tiering Stockage des documents de certification, PDFs générés, pièces jointes (jusqu'à 10GB/mois estimés)
Elastic Load Balancer Application LB Répartition de charge entre instances EC2, terminaison SSL, health checks automatiques
Route 53 — DNS & Domaine carbontrack.africa Gestion DNS haute disponibilité, routage géographique, enregistrement du domaine professionnel
AWS Backup Rétention 30 jours Sauvegardes automatiques cross-région (BDD + S3). Obligatoire pour conformité et continuité d'activité
💡 Pourquoi AWS et non un hébergeur local ? Aucun hébergeur local en Afrique Centrale ne propose de base de données managée avec sauvegardes automatiques, haute disponibilité Multi-AZ et SLA garanti. AWS est la norme industrielle mondiale et la seule option fiable pour une application de ce niveau de criticité.

Section 05

Sécurité, Monitoring & DevOps

Page 7

La nature critique des données traitées par CarbonTrack (données financières, informations d'entreprises, documents de certification) impose une infrastructure de sécurité et de surveillance de niveau entreprise.

Sécurité & Protection

Outil / ServiceFournisseurRôle & Nécessité
AWS WAF — Pare-feu Applicatif Sécurité Amazon Web Services Protection contre SQLi, XSS, DDoS, bots malveillants. Obligatoire pour toute application SaaS exposée sur Internet
AWS Secrets Manager Sécurité Amazon Web Services Stockage sécurisé des clés API (Airtel Money, Moov Money, SendGrid…). Rotation automatique des secrets. Interdit de stocker les clés en clair dans le code
Snyk Team — Analyse de vulnérabilités Snyk Scan continu des dépendances npm (600+ packages). Alerte et patch automatique des CVE (failles de sécurité connues) dans les librairies tierces
SSL/TLS — Certificats HTTPS AWS Certificate Manager Chiffrement de toutes les communications. Obligatoire pour App Store Apple (ATS) et Play Store Google (HTTPS enforced)

Monitoring & Observabilité

OutilFournisseurRôle & Nécessité
Datadog APM & Logs Monitoring Datadog Inc. Surveillance temps réel : performance API, latence base de données, alertes de surcharge. Dashboards opérationnels. SLA monitoring. Indispensable pour une application en production 24h/24
Sentry — Error Tracking Functional Software Capture et agrégation des erreurs JavaScript (web + mobile) en production. Stack traces complètes, contexte utilisateur, alertes email/Slack. Permet de corriger les bugs avant que les clients les signalent

CI/CD — Intégration & Déploiement Continus

OutilFournisseurRôle
GitHub Actions — CI/CD Pipeline GitHub (Microsoft) Automatisation complète : tests unitaires à chaque commit, build de l'application, déploiement automatique en production à chaque release validée. Zéro downtime deployments
Docker + Docker Compose Docker Inc. Conteneurisation de l'application. Environnements identiques dev/staging/production. Déploiements reproductibles et isolés

ServiceFournisseurUsage & Justification

Moov Money API Critique Moov Africa API officielle Moov Money. Même structure tarifaire. Couvre les utilisateurs Gabon, Congo, Cameroun ne disposant pas d'Airtel

Section 07

Distribution Mobile & App Stores

Page 9

La distribution de l'application mobile sur l'App Store d'Apple et le Google Play Store est obligatoire pour atteindre les utilisateurs iOS et Android. Ces deux plateformes représentent 100% du marché mobile mondial.

Comptes Développeurs & Distribution

ServiceFournisseurNécessité
Apple Developer Program Obligatoire Apple Inc. Sans ce compte, l'application iOS ne peut PAS être publiée sur l'App Store ni testée sur des iPhones physiques. Renouvellement annuel obligatoire
Google Play Console Obligatoire Google LLC Sans ce compte, l'application Android ne peut PAS être publiée sur le Play Store. Frais unique d'enregistrement
Expo Application Services (EAS) Expo (Meta) Build cloud iOS/Android sans Mac physique. Obligatoire pour compiler les binaires iOS (.ipa) sans posséder un Mac. Submit automatisé vers les stores
TestFlight (iOS Beta) Apple Inc. Distribution de versions bêta aux testeurs avant publication officielle. Inclus dans l'Apple Developer Program

Outils de Build & Compilation

OutilUsage
EAS Build (Expo) Compilation cloud des binaires iOS (.ipa) et Android (.aab/.apk). Indispensable sans infrastructure Mac locale
EAS Update (OTA Updates) Mises à jour Over-The-Air sans passer par le store review. Corrections de bugs immédiates (JS layer)
Fastlane Automatisation des soumissions store, captures d'écran automatisées, gestion des certificats iOS

⚠️ Contrainte critique iOS : Apple impose une révision humaine de chaque mise à jour (3–5 jours). Le renouvellement annuel du compte Apple Developer est non négociable — l'expiration entraîne le retrait immédiat de l'application de l'App Store.
